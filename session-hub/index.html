Domino Agent Herd setup

Welcome to Domino Agent Herd! Two quick steps get Codex and Claude Code running in your Domino workspaces. Come back any time with the Setup button.

Keep this App owner-only. Anyone with access can manage workspaces and agent sessions using the project owner’s permissions. Review the App’s sharing settings in Domino.

  1. 1

    Workspace connection

      Workspaces you start or resume from this App turn on Domino workspace SSH. The App then connects Codex and Claude Code in each workspace’s own compute environment. Environments need openssh-server, which Domino Standard Environments include.

      Connector environment

      Workspace SSH is off in this Domino deployment, so workspaces connect through an environment whose pre-run script starts the connector.

      Open environment in Domino

      Use an environment whose pre-run script points to this App.

      Agent sign-in

      Set up the agents you use: one or both. You sign in on your Mac and paste the result here. The App saves it as a Domino user environment variable, so every workspace you start is already signed in. Return here when a sign-in expires or to add the other agent.
